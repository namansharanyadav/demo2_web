# STUDENT INFORMATION FORM USING STREAMLIT
Introduction:-
Streamlit is an open-source Python library that allows developers to build interactive web applications easily. In this guide, we will create a Student Information Form using Streamlit, which enables users to input and submit student details. 

Prerequisites:-
Before we start, ensure you have the following installed:
Python (version 3.6 or later)
Streamlit (pip install streamlit)
